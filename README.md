# Muhammad Abbas — Portfolio Website (Production Ready)

Interactive frontend developer portfolio featuring custom circular image frames, Lenis smooth scrolling, GSAP animations, dynamic marquee, and a 100% fullscreen animated preloader.

## 📁 File Structure
- `index.html` - Semantic HTML5 document with embedded high-definition image data and standalone references.
- `styles.css` - Custom styling with circular avatar frames, animated borders, neon glow effects, and responsive design.
- `script.js` - ES6 JavaScript managing Lenis scroll, 0-100% preloader count-up, custom cursor, and GSAP ScrollTrigger animations.
- `images/` - Folder containing standalone JPEG copies of `IMG_3101.jpg` and `IMG_3376.jpg`.

## 🎨 New Features & Fixes
1. **Fixed Image Visibility**: Embedded Base64 image data directly into `index.html` so pictures render immediately when opened in any browser without needing a local HTTP server setup.
2. **Circular Image Design**: Designed circular photo frames (`border-radius: 50%`) with neon accent borders, floating badge, interactive hover zoom, and spinning dashed rings.
3. **Restored Original Copy**: Preserved all original headings, text content, and contact links ("Let's Work Together", Bacha Khan University, Mardan location details).
4. **Fullscreen Preloader**: Fullscreen loading screen (`100vw`/`100vh`) locking scroll until 100% completion before revealing the site.

## 🚀 How to Run
Simply open `index.html` in any web browser!
